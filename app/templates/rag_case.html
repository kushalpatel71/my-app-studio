Car Builds Knowledge Assistant

A public assistant for navigating the car website and interpreting its illustrative content. It does not provide mechanical instructions or measured performance claims.

Open the assistant Back to portfolio

From five guides to a traceable answer

  1. Administrator imports only allowlisted, original Markdown guides.
  2. Validate permissions and versions; split headings/paragraphs within 200 word pieces.
  3. CPU MiniLM creates real vectors; Chroma persists a complete snapshot.
  4. Embed the question and select the top three cosine-ranked passages.
  5. Send sufficiently relevant evidence to server-side Gemini.
  6. Reject unretrieved citation IDs and link accepted references to indexed passages.

The approved corpus covers navigation, sample-build interpretation, modification categories, account access, and assistant scope. Private accounts never enter retrieval.

Decisions and checks

Chroma uses the ONNX export of all-MiniLM-L6-v2 to avoid PyTorch’s runtime footprint on the small CPU server. SQLite FTS5 provides an exact-term baseline over the same active passages. A graph database would add operations without a demonstrated benefit for five guides.

Import activates a complete version only after embeddings and storage succeed. Unchanged reimport is idempotent. Changed source bytes require a version bump; current retrieval excludes old versions while historical citations remain readable.

Contribution and limits

The project owner selected the car topic, provisional career direction, additive routes and preservation requirements. AI implemented and tested this Build at the owner’s request. Personal understanding, peer feedback, group contributions and a successful live journey are not inferred.

Similarity is not proof of relevance. Citation validation proves an ID was retrieved; each claim still needs evidence review. The five-question evaluation is a small diagnostic set.
