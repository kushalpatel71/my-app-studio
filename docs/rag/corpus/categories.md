# Modification categories

Wheels is a label for the sample build's wheel and tire styling ideas. It does not certify wheel dimensions, tire sizes, or fitment for another car.

Suspension describes the sample's ride-height and handling concept. This glossary explains the category, not how to install or adjust suspension components.

Engine groups the example engine-related modification ideas. Performance groups the sample's broader performance-oriented ideas. Neither category supplies measured power gains or a safety guarantee.

Use these labels to read and compare the illustrative sample pages. Consult qualified sources for real mechanical work; the assistant corpus does not contain procedures, fitment tables, or measurements.
