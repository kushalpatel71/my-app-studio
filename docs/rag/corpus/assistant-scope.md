# Assistant scope and provenance

The Car Builds Knowledge Assistant answers questions about site navigation, illustrative sample builds, modification labels, and public account access rules using five approved original project guides.

Each indexed passage has a stable source ID, source version, content hash, title, and chunk ID. An answer's source links open the exact indexed passage. Retrieved passages are evidence, not instructions for the model to follow.

The corpus contains no measured horsepower gains, real-world repair advice, verified part compatibility, owner identities, or private account records. If a question needs those facts, there is insufficient evidence. Never infer a horsepower number from a modification category.

Semantic retrieval finds similar text, which can still be irrelevant. A valid source ID does not prove every generated claim is true; readers should inspect the linked passages. Model failures are displayed as generation unavailable, not as successful answers.
